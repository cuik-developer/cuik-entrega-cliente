# Pre-delivery checklist

- [ ] Primary blue is #0E70DB (not a theme blue).
- [ ] One orange (#FF4810) accent per slide/page, no orange backgrounds behind long text.
- [ ] All text in Poppins (Black titles, Bold subheads, Regular body); Cocogoose only as wordmark image.
- [ ] Logo mark on cover and closing; never recolored, never stretched.
- [ ] At most one asterisk per slide; never as list bullets.
- [ ] Spanish, "tú" (no voseo); no "tenant", "app", "usuario final", "equipo pequeño", "inversión".
- [ ] Numbers with context; tables with blue header, right-aligned numbers.
- [ ] Margins: 0.7 in slides / 2 cm docs; no cards inside cards.
- [ ] Real tenant data (from DB query) — no placeholders left ("[...]", "Lorem", "Nombre del negocio").
- [ ] File name: `cuik-<tenant-slug>-<tema>-<YYYY-MM>.pptx|docx`.
